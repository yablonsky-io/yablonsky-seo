# Yablonsky SEO 5.86.0

First public-release candidate for Yablonsky SEO — GEO & AEO.

## Highlights

- SEO metadata, XML sitemaps, Schema, redirects, 404 diagnostics, internal linking and bulk editing.
- WooCommerce, multilingual discovery and optional AI-assisted tools.
- Dedicated OAI-AdsBot policy, kept separate from existing search bot settings.
- Expanded crawler diagnostics and localization updates.

## Validation

The product owner confirmed the installed 5.86.0 returned **“Checks complete. No errors found.”** in Plugin Check. This is not official WordPress.org directory approval.

## Distribution

Release binaries are not uploaded yet. Once a GitHub Release is available, download the installable `Yablonsky-SEO-5.86.0.zip` from its Assets section. Do not mistake GitHub's source ZIP for the installer.
